# Centralized Monitoring System for Street Light Fault Detection and Location Tracking

## Project Description

This project is a centralized monitoring system designed to monitor street lights, detect faults, and track their locations. The system stores street light information in a MySQL database and provides backend APIs for retrieving and managing the data.

## Current Implementation

- MySQL database created
- Location data stored in the database
- Street light data stored in the database
- Sample street light records inserted
- Python Flask backend developed
- Flask successfully connected with MySQL
- REST API created for retrieving street light information
- Backend server tested successfully on localhost

## Technology Stack

- Python
- Flask
- Flask-CORS
- MySQL
- MySQL Connector Python
